# Snake Game 🐍

A classic arcade-style Snake game built using Python and the Turtle graphics module. Control the snake to eat food, grow longer, and avoid hitting the walls or its own tail!

## Features
* Smooth snake movement and real-time controls.
* Dynamic scoring system that saves your high score automatically (`data.txt`).
* Clean, modular object-oriented code structure (`main.py`, `snake.py`, `food.py`, `scoreboard.py`).

---

## How to Run Locally

Follow these steps to run the game on your computer:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/RichaVasisth47/Snake-Game.git](https://github.com/RichaVasisth47/Snake-Game.git)

Navigate into the project folder:
Bash
cd Snake-Game

Run the game using Python:
Bash
python main.py

Controls
Use the arrow keys on your keyboard to control the snake:

Up Arrow ⬆️ - Move Up

Down Arrow ⬇️ - Move Down

Left Arrow ⬅️ - Move Left

Right Arrow ➡️ - Move Right
